01 / Ready the stack

Launch sequence

Run these once on a new machine. The API needs all three data services available before it starts.

  1. Start Redis in Ubuntu WSL: sudo service redis-server start
  2. Start PostgreSQL and MongoDB, then configure your .env from .env.example.
  3. Run the database migrations and load realistic test data.
npm run migrate npm run seed npm run dev

03 / Configure Postman

One environment. Saved cookies.

  1. Create an environment variable called baseUrl with http://localhost:3000/api.
  2. Use Postman desktop with cookie handling enabled. Login saves the HTTP-only access and refresh cookies automatically.
  3. After creating a post or comment, copy its _id into variables named postId and commentId.

04 / Work the board

Endpoint checklist

Check each card as you go. Protected requests require the cookies created by login. Run deletion cards only with a throwaway account or post.

Authentication

POST
{{baseUrl}}/auth/register

New email + username + password. Expect 201.

POST
{{baseUrl}}/auth/login

Ahmed credentials above. Expect 200 and cookies.

POST
{{baseUrl}}/auth/refresh

No body. Expect 200 and a fresh access cookie.

POST
{{baseUrl}}/auth/logout

Run last. Expect 200.

People & feed

GET
{{baseUrl}}/users/{{userId}}

Public profile. Expect 200.

PUT
{{baseUrl}}/users/{{yourUserId}}

Body: {"update":"My new bio"}. Own account only.

POST
{{baseUrl}}/users/{{otherUserId}}/follow

Follow a different account. Expect 200.

DELETE
{{baseUrl}}/users/{{otherUserId}}/follow

Run after following. Expect 200.

GET
{{baseUrl}}/users/{{userId}}/followers

Returns follower list.

GET
{{baseUrl}}/feed/
