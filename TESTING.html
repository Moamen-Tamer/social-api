01 / Ready the stack

Launch sequence

Run these once on a new machine. The API needs all three data services available before it starts.

  1. Start Redis in Ubuntu WSL: sudo service redis-server start
  2. Start PostgreSQL and MongoDB, then configure your .env from .env.example.
  3. Run the database migrations and load realistic test data.
npm run migrate npm run seed npm run dev
02 / Sign in

Your seeded starting point

Demo userahmed_mohamed
Emailahmedmohamed@gmail.com
Passwordpassword
Start here. Ahmed already follows seeded accounts, so GET /feed/ returns useful data immediately after login.
03 / Configure Postman

One environment. Saved cookies.

  1. Use Postman desktop with cookie handling enabled. Login saves the HTTP-only access and refresh cookies automatically.
  2. After creating a post or comment, copy its _id into variables named postId and commentId.
{"email": "ahmedmohamed@gmail.com", "password": "password"}
04 / Work the board

Endpoint checklist

Check each card as you go. Protected requests require the cookies created by login. Run deletion cards only with a throwaway account or post.

Authentication

POST
http://localhost:3000/api/auth/register

New email + username + password. Expect 201.

POST
http://localhost:3000/api/auth/login

Ahmed credentials above. Expect 200 and cookies.

POST
http://localhost:3000/api/auth/refresh

No body. Expect 200 and a fresh access cookie.

POST
http://localhost:3000/api/auth/logout

Run last. Expect 200.

People & feed

GET
http://localhost:3000/api/users/{{userId}}

Public profile. Expect 200.

PUT
http://localhost:3000/api/users/{{yourUserId}}

Body: {"update": "My new bio"}. Own account only.

POST
http://localhost:3000/api/users/{{otherUserId}}/follow

Follow a different account. Expect 200.

DELETE
http://localhost:3000/api/users/{{otherUserId}}/follow

Run after following. Expect 200.

GET
http://localhost:3000/api/users/{{userId}}/followers

Returns follower list.

GET
http://localhost:3000/api/feed/

Ahmed's feed should contain seed posts.

POST
http://localhost:3000/api/posts/

Body: {"content": "My Postman test post"}. Save _id.

GET
http://localhost:3000/api/posts/{{postId}}

Post detail, comments, and likes.

PUT
http://localhost:3000/api/posts/{{postId}}

Update your own post content.

POST
http://localhost:3000/api/posts/{{postId}}/like

Second like returns 409 Conflict.

DELETE
http://localhost:3000/api/posts/{{postId}}/like

Run after liking.

POST
http://localhost:3000/api/comments/{{postId}}

Body: {"content": "A test comment"}.

GET
http://localhost:3000/api/comments/{{postId}}

Save your comment _id.

DELETE
http://localhost:3000/api/comments/{{postId}}/{{commentId}}

Only the comment author can delete.

GET
http://localhost:3000/api/notifications/

View notifications generated by follows and likes.

PATCH
http://localhost:3000/api/notifications/read

Mark all notifications as read.

DELETE
http://localhost:3000/api/posts/{{postId}}

Final post cleanup. Expect 204.

http://localhost:3000/api/users/{{yourUserId}}

Throwaway account only this cannot be undone.
